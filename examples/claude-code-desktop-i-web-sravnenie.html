Claude Code, Desktop и Web: чем они отличаются

Это не три конкурирующих продукта. Claude Code — агент для работы с кодом, а Desktop и Web — места, где его можно запустить рядом с обычным чатом. Ниже — что умеет каждый вариант и когда какой выбрать.

Сверено с официальной документацией Anthropic на 7 октября 2026. Продукты быстро меняются, поэтому спорные детали стоит проверять по ссылкам в конце.

Один движок Claude Code У всех поверхностей общий движок, поэтому файлы CLAUDE.md, настройки и MCP-серверы работают везде.

Claude Code в терминале

Запускается на вашем компьютере

Полнофункциональный CLI: правит файлы, запускает команды, пишет скрипты и работает в CI.

Claude Desktop

Приложение для macOS, Windows и Linux (бета)

Три вкладки: Chat, Cowork и Code. Вкладка Code — тот же Claude Code, но с окнами, diff и параллельными сессиями.

Claude Web

claude.ai в браузере и мобильное приложение

Обычный чат с Projects и Artifacts. Отдельно на claude.ai/code работает Claude Code в облаке.

Общая картина

Слово «Web» в запросе можно понять двояко: как обычный чат на claude.ai или как Claude Code в браузере. Поэтому в таблицах веб-колонка описывает оба случая, и я их разделяю.

Общая картина
Claude Code (терминал) Claude Desktop Claude Web
Что это Агентный инструмент для программирования: читает кодовую базу, редактирует файлы, запускает команды. Отдельное приложение с вкладками Chat, Cowork и Code. Вкладка Code содержит встроенный Claude Code. Чат на claude.ai; плюс claude.ai/code, где Claude Code работает в облачной среде Anthropic.
Где выполняется работа На вашей машине. Локально, в облаке, по SSH на удалённой машине или в WSL на Windows. Среду выбирают при старте сессии. Чат — на стороне Anthropic. Claude Code — в облачной виртуальной машине.
Доступ к вашим файлам Прямой: рабочая папка становится контекстом, загружать файлы не нужно. В локальных сессиях Code — прямой. В Chat файлы прикрепляются вручную. Чат: файлы нужно загрузить. Claude Code: клонирует репозиторий из GitHub, ваша локальная конфигурация не используется.
Установка Одна команда установки (macOS, Linux, WSL, Windows), Homebrew, WinGet, а также apt, dnf и apk. Отдельное приложение не нужно. Скачать и установить приложение. Отдельный CLI для вкладки Code не нужен. Ничего ставить не нужно: достаточно браузера или мобильного приложения.
Подписка и доступ Подписка Claude или аккаунт Anthropic Console. Также поддерживаются Amazon Bedrock, Google Cloud Agent Platform и Microsoft Foundry. Вкладка Code требует платной подписки (Pro, Max, Team или Enterprise). Чат есть и на бесплатном тарифе. Облачные сессии Code доступны на Pro, Max, Team и для части мест Enterprise.

Управление компьютером Через computer use, включается командой /mcp (macOS). Claude может открывать приложения и управлять экраном. Исследовательский предпросмотр, macOS и Windows, только тарифы Pro и Max. Нет

Подробнее о каждом варианте

Claude Code в терминале

Самый гибкий вариант и «оригинал» для всех остальных поверхностей.

  • Работает в вашей среде: правит файлы, запускает команды, делает коммиты и открывает pull request.
  • Комбинируется с другими утилитами: можно передать ему вывод лога и получить разбор, или запустить в CI.
  • Настраивается через CLAUDE.md, skills, hooks и MCP-серверы.
  • Единственная поверхность со сценарным запуском (claude -p) и командами агентов.
  • Подходит тем, кто привык к терминалу и хочет полный контроль.

Claude Desktop

Тот же Claude Code, но в графической оболочке, плюс обычный чат и Cowork.

  • Вкладка Code делит с CLI настройки, CLAUDE.md, hooks и skills. Сессию можно перенести командой /desktop.
  • Удобнее вести несколько задач: сессии лежат в боковой панели, у каждой свой git worktree.
  • Встроенный предпросмотр: Claude запускает приложение и сам проверяет свои правки через скриншоты.
  • Подключения без файлов настроек: коннекторы и плагины ставятся из интерфейса.
  • Чего нет: автодополнения кода, --print и agent teams.

Claude Web: чат на claude.ai

Универсальный вариант для людей и задач, не связанных с локальным проектом.

  • Работает без установки, синхронизируется с мобильным приложением.
  • Projects собирают файлы и инструкции в рабочее пространство; Artifacts превращают результат в документ, страницу или приложение.
  • Подходит для вопросов, текстов, анализа данных и исследований.
  • Не имеет автоматического доступа к вашей файловой системе: всё нужно загружать.

Claude Web: Claude Code в облаке

Подходит для задач, которые можно поставить и не следить за ними.

  • Claude клонирует репозиторий в изолированную виртуальную машину, вносит изменения и пушит ветку.
  • Удобно для параллельных задач, чужих репозиториев и вопросов по коду без локальной копии.
  • Работает и с телефона; сессию можно «телепортировать» в терминал.
  • Если нужны ваши локальные инструменты и окружение, лучше запускать локально или с Remote Control.

Что выбрать

Терминал
Нужны скрипты, CI, конвейеры или команды агентов; вы привыкли работать в терминале; Claude нужен на сервере или в SSH-сессии без графики.
Desktop
Ведёте несколько задач одновременно, хотите видеть diff и предпросмотр приложения, используете чат и Code в одной программе или хотите, чтобы Claude управлял приложениями на экране.
Web: Claude Code
Задача чётко сформулирована и не требует частых уточнений, нужно параллельно запустить несколько изменений или репозитория нет на вашей машине.
Web: чат
Нужны ответы на вопросы, тексты, анализ, исследование с источниками, документы или приложения в Artifacts, а проект на диске не задействован.

Можно сочетать. Сессию из терминала переносят в Desktop командой /desktop, а из облака забирают в терминал через claude --teleport. Удобная схема: ставите длинную задачу в облаке с телефона, а проверяете и дорабатываете её локально.

Оговорки

  • Требования к тарифам и список функций меняются. Для расчёта стоимости и лимитов сверяйтесь со страницей тарифов Claude.
  • Раздел про чат собран по оглавлению официального справочного центра. Детали отдельных функций и лимиты зависят от тарифа и настроек организации.
  • Часть возможностей Desktop (computer use, Dispatch) ограничена тарифами Pro и Max и недоступна на Team и Enterprise.
  • В корпоративных аккаунтах администратор может отключить облачные сессии, режим Bypass permissions и другие функции.
